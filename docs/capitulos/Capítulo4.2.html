Objetos, funciones y paquetes

Objetos: guardar un valor con un nombre

Con <- guardas un resultado en un objeto para usarlo después. Léelo como “se guarda en”.

creatinina <- 1.8                       # mg/dL
edad <- 67                              # años

creatinina * 88.4                       # µmol/L
[1] 159.12

Un objeto puede contener varios valores (un vector) con c():

creat <- c(0.9, 1.1, 1.8, 2.4, 3.1)     # creatinina de cinco pacientes (mg/dL)

creat * 88.4                            # operaciones sobre todo el vector
[1]  79.56  97.24 159.12 212.16 274.04
mean(creat)                             # promedio
[1] 1.86
creat > 2                               # ¿quiénes superan 2 mg/dL?
[1] FALSE FALSE FALSE  TRUE  TRUE
sum(creat > 2)                          # ¿cuántos?
[1] 2
Tip💡 Tip práctico: nombres de objetos

Usa nombres descriptivos, en minúscula y sin espacios ni tildes: tfg_basal, datos_ckd. Evita x1, base nueva, Resultados Final(2).

Tablas de datos: data.frame y tibble

Una base de datos es una tabla donde cada fila es un paciente (o una visita) y cada columna una variable. En el tidyverse se llama tibble.

library(tidyverse)

pacientes <- tibble(
  id        = 1:5,
  edad      = c(58, 71, 64, 80, 49),
  creat     = c(0.9, 1.1, 1.8, 2.4, 3.1),
  diabetes  = c(TRUE, FALSE, TRUE, TRUE, FALSE)
)
pacientes
# A tibble: 5 × 4
     id  edad creat diabetes
  <int> <dbl> <dbl> <lgl>   
1     1    58   0.9 TRUE    
2     2    71   1.1 FALSE   
3     3    64   1.8 TRUE    
4     4    80   2.4 TRUE

Para acceder a una columna se usa $; para filtrar o crear columnas, las funciones de dplyr (Cap. 5):

pacientes$creat                         # una columna
[1] 0.9 1.1 1.8 2.4 3.1
pacientes[2, ]                          # la fila 2

Funciones: la unidad de trabajo

Una función recibe argumentos (entre paréntesis) y devuelve un resultado: nombre_funcion(argumento1, argumento2).

round(mean(pacientes$creat), 2)         # funciones anidadas
[1] 1.86
mean(c(1, NA, 3), na.rm = TRUE)         # el argumento na.rm ignora los faltantes
[1] 2

El operador pipe |>

El pipe lee como “y luego”: pasa el resultado de la izquierda como primer argumento de la función de la derecha. Hace el código legible como una receta.

# Sin pipe: se lee de dentro hacia fuera
round(mean(pacientes$creat[pacientes$diabetes]), 2)
[1] 1.7
# Con pipe: se lee de izquierda a derecha
pacientes |>
  filter(diabetes) |>
  summarise(creat_media = mean(creat)) |>
  mutate(creat_media = round(creat_media, 2))
# A tibble: 1 × 1
  creat_media
        <dbl>
1         1.7

Crear tus propias funciones

Si repites un cálculo, escríbelo una vez como función. Ejemplo: clasificar la TFGe en categorías G de KDIGO.

categoria_g <- function(tfg) {
  case_when(
    tfg >= 90 ~ "G1",
    tfg >= 60 ~ "G2",
    tfg >= 45 ~ "G3a",
    tfg >= 30 ~ "G3b",
    tfg >= 15 ~ "G4",
    tfg <  15 ~ "G5"
  )
}

categoria_g(c(95, 62, 47, 33, 20, 8))
[1] "G1"  "G2"  "G3a" "G3b" "G4"  "G5"

Paquetes: instalar una vez, cargar cada sesión

install.packages("survival")   # se instala UNA vez en tu computadora
library(survival)              # se carga CADA sesión en que lo uses
survival::Surv                 # alternativa: usar una función sin cargar el paquete (paquete::función)
Advertencia⚠️ Cuidado: conflictos de nombres

Dos paquetes pueden tener funciones con el mismo nombre (por ejemplo, filter() existe en dplyr y en stats). Si algo se comporta distinto a lo esperado, usa dplyr::filter() para indicar de cuál paquete hablas.

Pedir ayuda sobre una función

?mean               # ayuda de la función mean
help("t.test")      # lo mismo
example(mean)       # ejemplos de uso
Importante🎯 En resumen
  • <- guarda un valor en un objeto; c() crea vectores.
  • Los tipos (numérico, texto, factor, fecha) importan: revísalos siempre.
  • Una base es un tibble: filas = pacientes, columnas = variables.
  • |> encadena pasos: “y luego”.
  • Si repites algo, escribe una función.
  • Instalar (install.packages) una vez; cargar (library) en cada sesión.
