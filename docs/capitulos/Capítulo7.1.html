¿Cómo son mis pacientes? Variables y su distribución

Nota🩺 Escenario

Es lunes y te entregan una base con 5 000 adultos con ERC y diabetes tipo 2 de tu clínica de nefrología (datos simulados). Aún no has ajustado ningún modelo ni comparado ningún fármaco. Antes de eso necesitas saber, simplemente, cómo son estos pacientes: ¿qué edad tienen?, ¿cuánta albuminuria?, ¿hay datos que faltan? La respuesta decide cómo los resumirás en la Tabla 1 y qué análisis tendrá sentido después.

Lo que vamos a hacer

  • Clasificar cada columna de la base según su tipo de variable.
  • Decidir, mirando un histograma, si una variable continua se resume con media (DE) o con mediana [RIC].
  • Usar el logaritmo para domar la albuminuria y contar los datos faltantes antes de resumir nada.

Paso 1. Dile a R qué tipo de variable es cada columna

El tipo de variable decide cómo se resume, cómo se grafica y qué modelo se usa después. Piénsalo como el rótulo de un tubo de laboratorio: si el rótulo está mal, todo lo que viene después sale mal.

Cualitativa nominal Sexo, etiología de la ERC, tipo de acceso vascular n (%)
Cualitativa ordinal Categoría G (G1-G5), A (A1-A3), riesgo KDIGO n (%) por categoría
Binaria Diabetes, ECV previa, evento renal n (%) del “sí”
Cuantitativa discreta Número de hospitalizaciones, de antihipertensivos Mediana [RIC] o media (DE)
Cuantitativa continua Edad, TFGe, creatinina, UACR, PAS Media (DE) o mediana [RIC]
Tiempo hasta evento Meses hasta diálisis Kaplan-Meier (Cap. 9)

Paso 3. Variables continuas: ¿media o mediana?

La media y la desviación estándar (DE) describen bien una distribución simétrica (en forma de campana). Si hay asimetría (una cola larga hacia un lado) o valores extremos, la media se deja arrastrar y conviene la mediana con el rango intercuartílico (RIC), que es el intervalo entre el cuartil 1 y el cuartil 3. Lo vemos dibujando la edad y la albuminuria:

library(patchwork)
p1 <- ggplot(ckd, aes(edad)) +
  geom_histogram(binwidth = 2, fill = "#0072B2", color = "white") +
  labs(x = "Edad (años)", y = "Pacientes", title = "Edad: simétrica")
p2 <- ggplot(ckd, aes(uacr)) +
  geom_histogram(bins = 50, fill = "#D55E00", color = "white") +
  labs(x = "UACR (mg/g)", y = "Pacientes", title = "UACR: cola larga a la derecha")
p1 + p2

La edad es una campana; la UACR tiene un cuerpo pequeño y una cola larga: unos pocos pacientes con albuminuria muy alta. Pongamos números a esa impresión con una función que calcula las medidas de resumen y la asimetría (0 = simétrica; muy positiva = cola a la derecha):

resumir <- function(x) {
  tibble(n = sum(!is.na(x)), media = mean(x, na.rm = TRUE), de = sd(x, na.rm = TRUE),
         mediana = median(x, na.rm = TRUE), q1 = quantile(x, .25, na.rm = TRUE),
         q3 = quantile(x, .75, na.rm = TRUE), minimo = min(x, na.rm = TRUE),
         maximo = max(x, na.rm = TRUE))
}
asimetria <- function(x) mean((x - mean(x))^3) / sd(x)^3     # 0 = simétrica

bind_rows(Edad = resumir(ckd$edad), UACR = resumir(ckd$uacr), .id = "variable") |>
  mutate(asimetria = c(asimetria(ckd$edad), asimetria(ckd$uacr)),
         across(where(is.numeric), \(x) round(x, 1)))
# A tibble: 2 × 10
  variable     n media    de mediana    q1    q3 minimo maximo asimetria
  <chr>    <dbl> <dbl> <dbl>   <dbl> <dbl> <dbl>  <dbl>  <dbl>     <dbl>
1 Edad      5000  63.8   10       64    57    71     32     90       0  
2 UACR      5000 214.   315.     118    59   248      3   5587       6.2

Qué vemos. En la edad, media y mediana casi coinciden y la asimetría es ≈ 0. En la UACR, la media (215) supera con holgura a la mediana (118) y la asimetría es 6.2: los valores extremos arrastran el promedio. Para la UACR se reporta mediana [Q1, Q3] = 118 [59, 248] mg/g.

Reglas prácticas para decidir:

  • Distribución simétrica → media (DE).
  • Asimétrica (UACR, triglicéridos, estancia hospitalaria, tiempo de espera) → mediana [Q1, Q3].
  • No decidas con una prueba de normalidad (Shapiro-Wilk y similares): con 5 000 pacientes siempre “rechazan” la normalidad por diferencias mínimas, y con 20 casi nunca. Decide mirando el histograma.
  • La DE no es el error estándar: la DE describe cuánto varían los pacientes; el error estándar describe cuánta incertidumbre tiene la media (Cap. 7.4).

Paso 4. El logaritmo simetriza la albuminuria

Muchas variables biológicas son aproximadamente log-normales: su logaritmo sí es una campana. Con la escala logarítmica la UACR se ve simétrica, y las líneas de KDIGO (30 y 300 mg/g) quedan a distancias razonables:

ggplot(ckd, aes(uacr)) +
  geom_histogram(bins = 40, fill = "#009E73", color = "white") +
  scale_x_log10(breaks = c(10, 30, 100, 300, 1000, 3000)) +
  geom_vline(xintercept = c(30, 300), linetype = "dashed") +
  annotate("text", x = c(11, 90, 1100), y = Inf, vjust = 2, label = c("A1", "A2", "A3")) +
  labs(x = "UACR (mg/g), escala logarítmica", y = "Pacientes",
       title = "Con escala log la UACR es simétrica; las líneas marcan los cortes de KDIGO")

El resumen natural de una variable log-normal es la media geométrica: el antilogaritmo de la media de los logaritmos.

c(media_aritmetica = mean(ckd$uacr), mediana = median(ckd$uacr),
  media_geometrica = exp(mean(log(ckd$uacr))),
  asimetria_del_log = asimetria(log(ckd$uacr)))
 media_aritmetica           mediana  media_geometrica asimetria_del_log 
     214.50740000      118.00000000      120.54426798        0.02848421

La media geométrica (120.5) casi coincide con la mediana (118) y la asimetría del logaritmo es 0.03, es decir, ≈ 0. Esa es la firma de una variable log-normal.

Paso 6. Datos faltantes: míralos antes de resumir

Antes de calcular nada, cuenta cuántos datos faltan por variable. La base que usamos está completa (la simulamos así), de modo que escribimos la función una vez y la probamos también con ckd_faltantes.csv, una versión simulada con huecos (se usa a fondo en el Cap. 13):

resumen_faltantes <- function(datos) {
  datos |>
    summarise(across(everything(), \(x) sum(is.na(x)))) |>
    pivot_longer(everything(), names_to = "variable", values_to = "faltantes") |>
    mutate(porcentaje = round(100 * faltantes / nrow(datos), 1)) |>
    arrange(desc(faltantes))
}

En la base completa todo es 0. En la versión con huecos, a uacr le falta un 32.8 % de los valores, a hba1c un 7.6 % y a pas un 4.2 %. Que falten no es lo mismo que “faltan al azar”; de por qué faltan y qué hacer se ocupa el Cap. 13.

Advertencia⚠️ Trampas frecuentes
  • Un número no siempre es una variable numérica. La categoría G codificada 1, 2, 3 es ordinal: el “promedio de las categorías” no significa nada. Declara el tipo con factor() o ordered().
  • log(0) es -Inf. Si hay ceros o valores bajo el límite de detección, no sumes 1 “por costumbre”: documenta qué hiciste (p. ej., sustituir por la mitad del límite de detección) y haz un análisis de sensibilidad.
Importante🎯 En resumen
  • El tipo de variable decide el resumen: n (%) para categóricas; media (DE) para continuas simétricas; mediana [RIC] para asimétricas.
  • Mira el histograma antes de elegir. La UACR casi siempre es asimétrica y se simetriza con escala logarítmica; su media geométrica ≈ su mediana.
  • Declara el denominador de cada porcentaje.
  • Cuenta los datos faltantes antes de resumir cualquier cosa.
