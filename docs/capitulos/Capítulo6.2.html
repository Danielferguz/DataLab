Diseños de muestreo: simple, estratificado y por conglomerados

Nota🩺 Escenario

No existe una lista de los 75 000 adultos de la región, pero sí una lista de las 600 comunidades. Puedes (a) sortear personas si tuvieras la lista, (b) separar la región en zona urbana y rural y sortear en cada una, o (c) sortear comunidades y medir a varios vecinos en cada una, que sale mucho más barato en el trabajo de campo. ¿Cuál estima mejor? ¿Y qué se paga por el ahorro?

Lo que vamos a hacer

  • Distinguir muestreo probabilístico de no probabilístico.
  • Programar cuatro diseños y compararlos con un experimento de muestreo repetido (conocemos la verdad).
  • Entender los pesos del sobremuestreo y el efecto de diseño de los conglomerados.

Paso 1: probabilística o no probabilística

En un muestreo probabilístico cada persona de la población tiene una probabilidad conocida y mayor que cero de ser elegida. Eso permite calcular el error y estimar sin sesgo. En uno no probabilístico (conveniencia, bola de nieve, “los que vienen a consulta”) no se conocen esas probabilidades y no se puede cuantificar el sesgo.

Diseño Cómo se elige Cuándo conviene
Aleatorio simple (MAS) Sorteo directo del listado Hay un listado completo y pequeño
Sistemático Un punto al azar y luego 1 de cada k Listado ordenado (registro de diálisis)
Estratificado MAS dentro de grupos (estratos) Grupos con distinta frecuencia; asegurar subgrupos pequeños
Por conglomerados Se sortean grupos y se mide a todos (o a parte) No hay listado de personas, pero sí de comunidades, hospitales, unidades
Bietápico / polietápico Conglomerados y luego personas dentro Encuestas nacionales de salud

Paso 2: cada diseño es una pequeña función

Con dplyr, cada diseño se escribe en pocas líneas. Trabajamos con la región simulada (pob) y un tamaño de muestra de 1 500 adultos. Cada función devuelve la muestra con una columna peso: la inversa de la probabilidad de selección (1 si todos tienen la misma probabilidad).

library(tidyverse)
source("R/simular_encuesta_erc.R")

pob <- simular_poblacion_erc()
N <- nrow(pob); n <- 1500
pob <- pob |>
  mutate(gedad = cut(edad, c(17, 39, 59, 100), labels = c("18-39", "40-59", "60+")),
         tam = ave(erc, cluster, FUN = length))        # tamaño de la comunidad (lo conoce el marco)
## 1. Aleatorio simple
muestra_mas <- function() slice_sample(pob, n = n) |> mutate(peso = 1)

## 2. Sistemático: un punto de partida al azar y 1 de cada k
muestra_sis <- function() {
  k <- floor(N / n); inicio <- sample(k, 1)
  pob[seq(inicio, N, by = k), ] |> mutate(peso = 1)
}

## 3. Estratificado proporcional (por grupo de edad)
muestra_estrat <- function() {
  pob |> group_by(gedad) |> slice_sample(prop = n / N) |> ungroup() |> mutate(peso = 1)
}

## 4. Por conglomerados en dos etapas: 60 comunidades y 25 adultos en cada una
muestra_cong <- function(n_cl = 60, por_cl = 25) {
  ids <- sample(unique(pob$cluster), n_cl)
  pob |> filter(cluster %in% ids) |> group_by(cluster) |> slice_sample(n = por_cl) |> ungroup() |>
    mutate(peso = (n_distinct(pob$cluster) / n_cl) * tam / por_cl)   # (1/prob. de la comunidad) x (1/prob. dentro de ella)
}

En el diseño por conglomerados, un adulto de una comunidad pequeña tiene más probabilidad de salir (se eligen 25 de pocos) que uno de una comunidad grande. Para estimar sin sesgo hay que ponderar por peso. Siempre fija la semilla (set.seed()) antes de sortear y guarda los ID sorteados: así cualquiera puede reproducir y auditar tu muestra.

Paso 3: ¿qué diseño estima mejor? Un experimento repetido

Como conocemos toda la población, podemos sacar 1 000 muestras de cada diseño y mirar (a) si el estimador cae en promedio sobre la verdad (sesgo) y (b) cuánto varía de una muestra a otra. Para los conglomerados calculamos dos estimaciones de cada muestra: con y sin pesos.

set.seed(1)
reps <- 1000
prev_verdadera <- mean(pob$erc)

# De cada muestra devuelve la prevalencia ponderada y la no ponderada
estimar <- function(f) {
  replicate(reps, { m <- f(); c(ponderada = weighted.mean(m$erc, m$peso), sin_pesos = mean(m$erc)) })
}
est <- list(mas = estimar(muestra_mas), sis = estimar(muestra_sis),
            estrat = estimar(muestra_estrat), cong = estimar(muestra_cong))

# Error estándar teórico de una MAS del mismo tamaño: referencia para el efecto de diseño
ee_mas <- sqrt(prev_verdadera * (1 - prev_verdadera) / n * (1 - n / N))

resultados <- tibble(
  diseno = c("Aleatorio simple", "Sistemático", "Estratificado (edad)",
             "Conglomerados 60 × 25, ponderado", "Conglomerados 60 × 25, SIN ponderar"),
  estimaciones = list(est$mas["ponderada", ], est$sis["ponderada", ], est$estrat["ponderada", ],
                      est$cong["ponderada", ], est$cong["sin_pesos", ])
)

resumen <- resultados |>
  mutate(media = map_dbl(estimaciones, mean),
         desv_est = map_dbl(estimaciones, sd),
         sesgo = media - prev_verdadera,                       # ¿acierta en promedio?
         efecto_diseno = (desv_est / ee_mas)^2) |>             # varianza relativa a una MAS
  select(-estimaciones)

resumen |> mutate(across(c(media, desv_est, sesgo), \(x) round(100 * x, 2)),
                  efecto_diseno = round(efecto_diseno, 2))

Las tres primeras columnas están en puntos porcentuales; la prevalencia verdadera es 7.57 %. Mira también la figura:

  mutate(diseno = factor(diseno, levels = rev(resultados$diseno)))

# Efecto de diseño teórico de estratificar por edad: varianza dentro de los estratos / varianza total
estratos <- pob |> group_by(gedad) |> summarise(peso_h = n() / N, p_h = mean(erc))
prev_edad <- estratos$p_h
deff_estrat <- sum(estratos$peso_h * estratos$p_h * (1 - estratos$p_h)) / (prev_verdadera * (1 - prev_verdadera))
deff_estrat
[1] 0.9678443

Lo que enseña el experimento:

  • Los diseños probabilísticos, bien analizados, aciertan en promedio: el sesgo de las cuatro primeras filas es de a lo más 0.04 puntos.
  • Ignorar los pesos sesga el diseño por conglomerados: sin ponderar se queda 0.36 puntos por encima de la verdad, porque las comunidades pequeñas (en su mayoría rurales, con más ERC) tienen más probabilidad de ser elegidas y quedan sobrerrepresentadas.
  • Los conglomerados aumentan el error: su efecto de diseño es 1.56 (la varianza es 1.6 veces la de una MAS del mismo tamaño). Medir 25 vecinos de la misma comunidad aporta menos información que medir 25 personas distintas. Se hace por logística y costo, y se paga con una muestra efectiva menor.
  • Estratificar por edad casi no ayuda aquí (efecto de diseño 0.96). La ganancia teórica es solo de un 3 %, porque aunque la ERC aumenta con la edad (de 3 % a 16 %), la mayor parte de la variación está dentro de cada grupo: estratificar paga cuando el desenlace difiere mucho entre estratos.
  • El sistemático gana (0.74) por una razón accidental: el listado está ordenado por comunidad, y eso equivale a estratificar por comunidad. Cuidado: si el listado tiene un patrón periódico que coincide con k (por ejemplo, un turno fijo cada 7 días), el sistemático puede sesgar.

Cada cifra tiene su propio error de simulación: con 1 000 réplicas, un efecto de diseño tiene un margen de unos ±10 %, así que las diferencias pequeñas (el efecto de la MAS debería ser 1) no se interpretan.

Paso 4: estratificar, proporcional o desproporcionado

  • Proporcional: cada estrato aporta a la muestra en proporción a su tamaño. Mejora un poco la precisión y no exige ponderar.
  • Desproporcionado (sobremuestreo): se toman más personas de un grupo pequeño de interés (zona rural, pacientes en diálisis, mayores de 80 años) para tener precisión dentro de ese grupo. El costo es que las personas ya no tienen la misma probabilidad de selección, y el análisis debe usar pesos.

La zona rural es el 29 % de los adultos. Con 1 500 personas en MAS esperaríamos unas 430 rurales. Si queremos comparar urbano y rural reservamos 750 y 750:

N_h <- pob |> count(area, name = "N_h")
N_h |> mutate(proporcion = N_h / sum(N_h), esperados_en_1500 = round(1500 * proporcion),
              n_h = 750, peso = N_h / n_h)          # peso = inversa de la probabilidad = N_h / n_h
# A tibble: 2 × 6
  area     N_h proporcion esperados_en_1500   n_h  peso

Cada persona rural “representa” a 29 adultos; cada persona urbana, a 72. Esos son los pesos de muestreo. ¿Qué pasa si los ignoramos? Repetimos el diseño 500 veces:

muestra_desprop <- function() {
  pob |> group_by(area) |> slice_sample(n = 750) |> ungroup() |>
    left_join(N_h, by = "area") |> mutate(peso = N_h / 750)
}

set.seed(2)
est_desprop <- replicate(500, { m <- muestra_desprop(); c(sin_pesos = mean(m$erc), con_pesos = weighted.mean(m$erc, m$peso)) })

tibble(
  analisis = c("Sin pesos", "Con pesos N_h / n_h"),
  media_de_500_muestras = round(100 * rowMeans(est_desprop), 2),
  sesgo = round(100 * (rowMeans(est_desprop) - prev_verdadera), 2)
)

Sin pesos, la zona rural (la mitad de la muestra, pero solo el 29 % de la población) pesa demasiado y la prevalencia sale 0.75 puntos por encima de la verdad. Con los pesos, el sesgo desaparece.

Paso 5: conglomerados, correlación intraclase y efecto de diseño

Personas de la misma comunidad se parecen entre sí (mismo acceso a salud, dieta, exposiciones). Esa semejanza se mide con el coeficiente de correlación intraclase (ICC, \(\rho\)). Con conglomerados de tamaño promedio \(\bar m\), el efecto de diseño (deff) es

\[ \text{deff} \approx 1 + (\bar m - 1)\,\rho \]

Es el factor por el que se multiplica la varianza respecto de una MAS del mismo tamaño; el tamaño de muestra efectivo es \(n_{ef} = n/\text{deff}\).

## ICC aproximado con análisis de varianza de un factor (ERC como 0/1)
a <- aov(erc ~ factor(cluster), data = pob)
ms <- summary(a)[[1]]$`Mean Sq`
m_prom <- mean(table(pob$cluster))
icc <- (ms[1] - ms[2]) / (ms[1] + (m_prom - 1) * ms[2])

deff_teorico <- 1 + (25 - 1) * icc
c(icc = icc, deff_con_25_por_comunidad = deff_teorico, n_efectivo = n / deff_teorico)
                      icc deff_con_25_por_comunidad                n_efectivo 
               0.02634444                1.63226656              918.96755033

Un ICC de apenas 0.026 parece insignificante, pero con 25 personas por conglomerado el deff teórico es 1.63: las 1 500 personas valen como unas 919. La simulación del Paso 3 dio 1.56: la fórmula es una aproximación, pero acierta el orden de magnitud. Cuantas más personas por conglomerado, mayor el costo estadístico; suele ser mejor más conglomerados con menos personas cada uno.

Advertencia⚠️ Los datos agrupados no son independientes

Analizar una encuesta por conglomerados con t.test() o glm() ordinarios subestima el error estándar (IC demasiado estrechos, p demasiado pequeños). Lo mismo ocurre con pacientes agrupados en centros o unidades de diálisis. Hay que incorporar el diseño (6.3, y modelos mixtos en el Cap. 14).

Importante🎯 En resumen
  • Solo el muestreo probabilístico permite estimar sin sesgo y cuantificar el error.
  • Estratifica por variables muy relacionadas con el desenlace (más precisión) o para asegurar subgrupos pequeños (sobremuestreo, que exige pesos).
  • Los conglomerados abaratan el trabajo de campo pero aumentan la varianza: deff ≈ 1 + (m − 1)ρ; sin pesos, además, pueden sesgar.
  • Un listado ordenado y un sistemático pueden coincidir con un patrón periódico: revisa el orden.
  • Escribe el diseño como código reproducible con semilla.
