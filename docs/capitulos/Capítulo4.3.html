Importar datos

Los datos de nefrología llegan en formatos diversos: el registro del servicio en Excel, el laboratorio en CSV, bases de investigación en Stata o SPSS. Este subcapítulo muestra cómo leer cada formato y, sobre todo, cómo revisar lo que se importó antes de analizar.

library(tidyverse)
library(readxl)     # Excel
library(haven)      # Stata, SPSS, SAS
Importante🎯 En resumen: qué función usar
Formato Función Paquete
CSV (coma) read_csv() readr (tidyverse)
CSV (punto y coma, coma decimal) read_csv2() readr
Texto con otro separador read_delim(delim = "\t") readr
Excel (.xlsx, .xls) read_excel(hoja) readxl
Stata (.dta) read_dta() haven
SPSS (.sav) read_sav() haven
R (.rds) read_rds() readr

read_csv() te informa cuántas filas y columnas leyó y qué tipo asignó a cada una. Léelo siempre: si una columna numérica aparece como chr (texto), algo anda mal (ver 4.5 y Cap. 5).

CSV de Latinoamérica y Europa: ; y coma decimal

Con frecuencia el Excel exporta CSV con ; como separador y , como decimal. Si usas read_csv() los números quedan como texto. Usa read_csv2():

read_csv2("Bases/ejemplo_pacientes_puntoycoma.csv") |> head(3)
# A tibble: 3 × 9
     id  edad sexo  hba1c   pas tfg_basal  uacr   ecv isglt2

1     1    70 Mujer   7.5   130      47.9    77     0      1
2     2    64 Mujer   9.6   146      42      70     0      0
3     3    72 Mujer   9.1   136      35.1   230     0      0
Tip💡 Tip práctico: especificar las columnas

Para evitar sorpresas, indica tú el tipo de cada columna y qué valores significan “faltante”:

read_csv("Bases/ckd_isglt2.csv",
         col_types = cols(id = col_integer(), sexo = col_factor(), uacr = col_double()),
         na = c("", "NA", "999", "-"))

Advertencia⚠️ Excel esconde problemas
  • Fechas guardadas como números de serie o como texto.
  • Celdas combinadas, encabezados en varias filas, colores con significado (“rojo = fallecido”).
  • Columnas numéricas con un texto ("ND", "<0.5") que las convierte enteras en texto.
  • Varias hojas con la misma estructura (una por año).

Cuando puedas, pide los datos en CSV y un diccionario de datos. Si debes usar Excel, usa skip = 3 para saltar filas de título y range = "A4:J200" para leer un rango.

Tip💡 Tip práctico: lista de verificación al importar
  1. ¿El número de filas coincide con el número de pacientes esperado?
  2. ¿Cada columna tiene el tipo correcto (número, texto, fecha)?
  3. ¿Los mínimos y máximos son clínicamente plausibles (edad 250, PAS 0, TFGe negativa)?
  4. ¿Los faltantes están codificados como NA (no como 999 o "-")?
  5. ¿Hay IDs duplicados?
  6. ¿Las categorías están escritas de una sola manera?

Guardar y exportar

write_csv(ckd, "datos/procesados/ckd_limpio.csv")   # CSV: universal
write_rds(ckd, "datos/procesados/ckd_limpio.rds")   # RDS: conserva tipos y factores (solo R)
Advertencia⚠️ Privacidad de datos clínicos
  • Nunca subas a un repositorio público, a un servicio en la nube ni a una herramienta de IA datos con identificadores (nombre, DNI, historia clínica, fecha de nacimiento exacta).
  • Trabaja con un código de paciente y guarda la tabla de equivalencias aparte y protegida.
  • Cumple las normas de tu institución y del comité de ética.
Importante🎯 Para llevarte
  • Cada formato tiene su función; CSV es el más seguro.
  • read_csv2() para CSV con ; y coma decimal.
  • Con haven, usa as_factor() para convertir etiquetas a factores.
  • Revisa siempre: dimensiones, tipos, rangos, faltantes y duplicados.
  • Protege los datos identificables.
