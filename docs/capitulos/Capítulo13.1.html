¿Por qué faltan los datos? Los mecanismos MCAR, MAR y MNAR

Nota🩺 Escenario

Estás analizando la albuminuria (UACR) de tus pacientes y notas que a un tercio no se les pidió. ¿Se perdieron muestras por un fallo de laboratorio? ¿El nefrólogo no la pide en pacientes mayores o con TFGe muy baja? ¿O faltan justamente los pacientes más enfermos, que ya no vienen a consulta? El problema no es cuántos faltan, sino por qué.

Es la pregunta de la hoja arrancada: no basta con saber que faltan hojas de la historia clínica; importa qué decidió que faltaran. Rubin (1976) clasificó las respuestas en tres mecanismos, según de qué depende el indicador de dato observado (\(R=1\) si el dato se midió, \(R=0\) si falta).

Lo que vamos a hacer

  • Reconocer MCAR, MAR y MNAR con ejemplos de nefrología.
  • Dibujar cada mecanismo como un DAG (con el indicador de faltante).
  • Ver con una simulación cuánto sesga cada uno al análisis de casos completos.

Paso 1: los tres mecanismos, con ejemplos

Mecanismo ¿De qué depende \(R\)? Ejemplo con la UACR Otro ejemplo
MCAR (missing completely at random) De nada Se perdieron muestras de orina por un fallo de laboratorio, al azar Un tubo de PTH se rompió en la centrífuga
MAR (missing at random) De variables observadas Falta más UACR en pacientes mayores o con TFGe baja (la edad y la TFGe sí están en la base) La hemoglobina se pide menos a quien tiene TFGe alta
MNAR (missing not at random) Del propio valor que falta (o de algo no observado) Quienes tienen albuminuria alta están más graves y no regresan a la consulta En hemodiálisis, falta la hemoglobina de quien está tan baja que se hospitaliza

La distinción importa porque solo MCAR se puede ignorar sin sesgo. MAR se puede corregir usando lo observado. MNAR no se corrige con los datos: hace falta un supuesto externo (13.6).

Paso 2: los tres mecanismos como DAG

Añadimos al DAG el indicador de faltante \(R\) y dibujamos de qué depende. \(X\) es la variable parcialmente observada (UACR), \(Y\) el desenlace y \(Z\) una covariable siempre observada (edad, TFGe).

panel <- function(aristas, titulo) {
  nodos <- tribble(~nombre, ~x, ~y, ~etiqueta, ~rol,
    "Z", 1, 1.6, "Edad, TFGe\n(observadas)", "otro",
    "X", 2, 1.6, "UACR\n(verdadera)", "exposicion",
    "Y", 3, 1.6, "Desenlace", "desenlace",
    "R", 2, 0.4, "¿Se midió\nla UACR? (R)", "colisionador")
  dibujar_dag(nodos, aristas, tam_texto = 3, expandir = c(0.2, 0.3)) + labs(title = titulo) +
    theme(legend.position = "none", plot.title = element_text(face = "bold", size = 11))
}
base <- tribble(~de, ~a, "Z", "X", "X", "Y", "Z", "Y")
library(patchwork)
panel(base, "MCAR: R no depende de nada") +
  panel(bind_rows(base, tribble(~de, ~a, "Z", "R", "Y", "R")), "MAR: R depende de lo observado") +
  panel(bind_rows(base, tribble(~de, ~a, "X", "R")), "MNAR: R depende de X (el dato que falta)")

Qué vemos: en MAR, \(R\) depende de \(Z\) e \(Y\), que sí observamos: si ajustamos por ellos, se puede recuperar la información. En MNAR, \(R\) depende de \(X\), el valor que no vemos: ningún ajuste con los datos observados lo corrige.

Paso 3: ¿cuánto sesga cada mecanismo? (simulación)

Borramos el 33 % de las UACR con cada mecanismo (la función generar_faltantes() está en R/simular_faltantes.R) y comparamos el análisis de casos completos con los datos completos (la verdad). Primero, un vistazo a qué valores sobreviven: la curva naranja es la distribución de ln(UACR) en todos los pacientes; la azul, solo en los que conservan el dato.

observados <- map_dfr(c("MCAR", "MAR", "MNAR"), \(m) {
  d <- generar_faltantes(oraculo, m)
  tibble(mecanismo = m, luacr = log(d$uacr[!is.na(d$uacr)]))
}) |> mutate(mecanismo = fct_inorder(mecanismo))

ggplot() +
  geom_density(data = tibble(luacr = log(oraculo$uacr)), aes(luacr), color = "#D55E00", linewidth = 1) +
  geom_density(data = observados, aes(luacr), color = "#0072B2", linewidth = 1) +
  facet_wrap(~ mecanismo) +
  labs(x = "ln(UACR)", y = "Densidad",
       caption = "Naranja: todos los pacientes (verdad). Azul: solo los que conservan la UACR. Datos simulados.") +
  theme_minimal(base_size = 11)

Qué vemos: con MCAR las dos curvas coinciden. Con MAR la azul se desplaza un poco a la izquierda. Con MNAR se desplaza mucho: los pacientes con albuminuria alta desaparecieron.

Ahora el efecto de ese sesgo sobre el análisis: el efecto estimado del iSGLT2 con casos completos, frente al de los datos completos.

formula_mod <- pendiente_tfg ~ isglt2 + I(edad / 10) + sexo + hba1c + pas + tfg_basal + log(uacr) + ecv

resumen_mecanismo <- function(mec) {
  d <- generar_faltantes(oraculo, mec)
  m_cc <- lm(formula_mod, data = d)                       # lm() elimina las filas con faltantes: casos completos
  tibble(mecanismo = mec,
         `% falta UACR` = 100 * mean(is.na(d$uacr)),
         `ln(UACR) medio (observados)` = mean(log(d$uacr), na.rm = TRUE),
         `Efecto iSGLT2 (casos completos)` = unname(coef(m_cc)["isglt2"]),
         `n analizado` = nobs(m_cc))
}
m_verdad <- lm(formula_mod, data = oraculo)

tab_meca <- bind_rows(
  tibble(mecanismo = "Datos completos (verdad)", `% falta UACR` = 0,
         `ln(UACR) medio (observados)` = mean(log(oraculo$uacr)),
         `Efecto iSGLT2 (casos completos)` = unname(coef(m_verdad)["isglt2"]), `n analizado` = nrow(oraculo)),
  map_dfr(c("MCAR", "MAR", "MNAR"), resumen_mecanismo)
)
knitr::kable(tab_meca, digits = 2)
mecanismo % falta UACR ln(UACR) medio (observados) Efecto iSGLT2 (casos completos) n analizado
Datos completos (verdad) 0.00 4.79 1.34 5000
MCAR 32.60 4.80 1.30 2980
MAR 32.80 4.72 1.24 2991
MNAR 32.66 4.49 1.16 2996

Qué vemos:

  • MCAR: sin sesgo sistemático. El promedio observado de ln(UACR) (4.8) coincide con el real (4.79); el efecto (1.3 frente a 1.34) difiere solo por el azar muestral y se pierde precisión: quedan 2 980 de 5 000 pacientes (también faltan HbA1c y PAS).
  • MAR (depende de edad, TFGe, tratamiento y desenlace): el promedio observado queda sesgado (4.72) y el efecto estimado se desvía (1.24 frente a 1.34).
  • MNAR (falta más cuando la UACR es alta): el promedio observado queda muy sesgado (4.49 frente a 4.79) y el efecto estimado se desvía más (1.16).
Advertencia⚠️ MAR no significa “al azar”

MAR significa que, dado lo que observas, la falta es “como al azar”. Que los mayores tengan más faltantes no viola MAR (si observas la edad); que los más graves falten más sí lo viola si la gravedad no se mide. MAR es un supuesto no verificable: se defiende con conocimiento del proceso que generó los faltantes (pregunta al personal clínico y revisa el protocolo), no con los datos.

Importante🎯 En resumen
  • MCAR: sin sesgo, solo pierdes precisión. MAR: la falta depende de lo observado; se corrige ajustando o imputando. MNAR: depende del valor perdido; hace falta un supuesto externo y análisis de sensibilidad.
  • MAR y MNAR no se distinguen con los datos observados: se argumentan con conocimiento clínico.
  • Dibuja el indicador de faltante en el DAG: ¿qué flechas lo causan?
  • Los datos faltantes no son solo un problema de tamaño de muestra: pueden sesgar.
