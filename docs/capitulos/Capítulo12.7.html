Efectos causales con desenlaces de supervivencia

El desenlace es “tiempo hasta evento”

Con desenlaces de supervivencia (Cap. 9), los métodos causales se adaptan de tres maneras:

Estrategia Cómo Estimando
Kaplan-Meier ponderado KM con los pesos IPW Riesgo (o supervivencia) marginal a cada tiempo; DR y RR a t
Cox ponderado coxph con pesos y errores robustos HR marginal
Estandarización con un modelo de supervivencia Predecir la curva de cada paciente con y sin tratamiento y promediar Riesgo estandarizado a t, ATE, ATT 
library(tidyverse)
library(survival)
library(boot)
source("R/funciones_epi.R")

oraculo <- read_csv("Bases/ckd_isglt2_oraculo.csv") |>
  mutate(sexo = factor(sexo, levels = c("Mujer", "Hombre")), luacr = log(uacr))
ckd <- oraculo |> select(-fragilidad, -pendiente_0, -pendiente_1, -ite, -starts_with("evento_36m"))

## Verdad (oráculo): efectos sobre el riesgo a 36 meses y HR simulado
r1 <- mean(oraculo$evento_36m_1); r0 <- mean(oraculo$evento_36m_0)
verdad <- c(riesgo_si_todos = r1, riesgo_si_nadie = r0, DR = r1 - r0, RR = r1 / r0, HR = 0.70)
round(verdad, 3)
riesgo_si_todos riesgo_si_nadie              DR              RR              HR 
          0.126           0.172          -0.045           0.736           0.700

El efecto causal verdadero sobre el riesgo de evento renal a 36 meses: 12.6 % si todos reciben el iSGLT2 y 17.2 % si nadie; DR = −4.5 puntos; RR = 0.74; el HR constante simulado es 0.70.

Preparar los pesos

x <- "I(edad / 10) + sexo + hba1c + pas + tfg_basal + luacr + ecv"
ckd$ps <- fitted(glm(as.formula(paste("isglt2 ~", x)), data = ckd, family = binomial))
ckd$w <- ifelse(ckd$isglt2 == 1, 1 / ckd$ps, 1 / (1 - ckd$ps))
ckd <- ckd |> mutate(trat = factor(isglt2, labels = c("No inicia", "Inicia iSGLT2")))

Kaplan-Meier ponderado

El KM ponderado estima la curva en la pseudopoblación balanceada. Se compara con la curva cruda:

curva <- function(datos, pesos, nombre) {
  sf <- survfit(Surv(tiempo_meses, evento) ~ trat, data = datos, weights = pesos)
  tibble(tiempo = sf$time, riesgo = 1 - sf$surv, trat = rep(levels(datos$trat), sf$strata), tipo = nombre)
}
bind_rows(curva(ckd, NULL, "Cruda"), curva(ckd, ckd$w, "Ponderada por IPW")) |>
  ggplot(aes(tiempo, riesgo, color = trat)) +
  geom_step(linewidth = 1) +
  facet_wrap(~ tipo) +
  scale_color_manual(values = c("No inicia" = "#999999", "Inicia iSGLT2" = "#0072B2"), name = NULL) +
  scale_y_continuous(labels = scales::percent_format()) +
  labs(x = "Meses", y = "Riesgo acumulado de evento renal", caption = "Datos simulados.") +
  theme_minimal(base_size = 11) + theme(legend.position = "bottom")

Calculamos la DR y el RR a 12, 24 y 36 meses de forma explícita:

riesgo_ponderado <- function(datos, pesos, t) {
  sf <- survfit(Surv(tiempo_meses, evento) ~ isglt2, data = datos, weights = pesos)
  s <- summary(sf, times = t, extend = TRUE)
  r <- 1 - s$surv; c(riesgo_0 = r[1], riesgo_1 = r[2], DR = r[2] - r[1], RR = r[2] / r[1])
}
tibble(meses = c(12, 24, 36)) |>
  mutate(res = map(meses, \(t) as_tibble(as.list(riesgo_ponderado(ckd, ckd$w, t))))) |>
  unnest(res) |> mutate(across(-meses, \(x) round(x, 3)))
# A tibble: 3 × 5
  meses riesgo_0 riesgo_1     DR    RR
  <dbl>    <dbl>    <dbl>  <dbl> <dbl>
1    12    0.071    0.037 -0.035 0.515
2    24    0.136    0.079 -0.056 0.586
3    36    0.19     0.109 -0.081 0.572

A los 36 meses, el riesgo ponderado es 19.0 % sin iSGLT2 y 10.9 % con él: DR ≈ −8 puntos, RR ≈ 0.57. Es mayor que la verdad (−4.5 puntos; RR 0.74) por la fragilidad no medida. Igual que antes: el método (ponderación para supervivencia) es correcto; el supuesto de intercambiabilidad condicional es el que falla.

Cox ponderado: el HR marginal

cx_cond <- coxph(Surv(tiempo_meses, evento) ~ isglt2 + I(edad / 10) + sexo + hba1c + pas + tfg_basal + luacr + ecv, data = ckd)
cx_marg <- coxph(Surv(tiempo_meses, evento) ~ isglt2, data = ckd, weights = w, robust = TRUE)
cx_crudo <- coxph(Surv(tiempo_meses, evento) ~ isglt2, data = ckd)

hr <- function(m) exp(coef(m)["isglt2"])
tibble(modelo = c("Cox crudo", "Cox ajustado (condicional)", "Cox ponderado (marginal)", "Verdad"),
       HR = c(hr(cx_crudo), hr(cx_cond), hr(cx_marg), 0.70)) |> mutate(HR = round(HR, 2))
# A tibble: 4 × 2
  modelo                        HR
  <chr>                      <dbl>
1 Cox crudo                   0.54
2 Cox ajustado (condicional)  0.55
3 Cox ponderado (marginal)    0.55
4 Verdad                      0.7

El Cox ponderado con errores robustos (robust = TRUE) estima el HR marginal; el Cox ajustado, el HR condicional. Con riesgos proporcionales constantes y sin confusión no medida coincidirían; aquí ambos (~0.55) se desvían del 0.70 verdadero por la fragilidad.

Advertencia⚠️ HR marginal ≠ HR condicional

El HR no es colapsable: el HR marginal (poblacional) generalmente difiere del condicional (a covariables dadas), aun sin confusión. Por eso se prefieren riesgos acumulados (DR, RR a un tiempo) para comunicar efectos causales.

Estandarización con un modelo de Cox

Se ajusta un Cox con covariables, se predice la curva de cada paciente bajo ambos tratamientos y se promedia:

riesgo_estandarizado <- function(datos, t = 36) {
  m <- coxph(Surv(tiempo_meses, evento) ~ isglt2 + I(edad / 10) + sexo + hba1c + pas + tfg_basal + luacr + ecv, data = datos)
  s1 <- summary(survfit(m, newdata = mutate(datos, isglt2 = 1)), times = t, extend = TRUE)$surv
  s0 <- summary(survfit(m, newdata = mutate(datos, isglt2 = 0)), times = t, extend = TRUE)$surv
  r1 <- 1 - mean(s1); r0 <- 1 - mean(s0)
  c(riesgo_0 = r0, riesgo_1 = r1, DR = r1 - r0, RR = r1 / r0)
}
round(riesgo_estandarizado(ckd), 3)
riesgo_0 riesgo_1       DR       RR 
   0.188    0.111   -0.078    0.588

DR ≈ −8 puntos y RR ≈ 0.59, coherente con el KM ponderado (los dos métodos comparten el mismo conjunto de confusores).

IC por bootstrap 

dr_ipw <- function(datos, i) {
  d <- datos[i, ]
  ps <- fitted(glm(as.formula(paste("isglt2 ~", x)), data = d, family = binomial))
  w <- ifelse(d$isglt2 == 1, 1 / ps, 1 / (1 - ps))
  riesgo_ponderado(d, w, 36)["DR"]
}
set.seed(11)
b <- boot(ckd, dr_ipw, R = 200)
c(DR_36m = b$t0, quantile(b$t, c(0.025, 0.975))) |> round(3)
DR_36m.DR      2.5%     97.5% 
   -0.081    -0.106    -0.058

Si pudiéramos medir la confusión: la verdad reaparece

Para comprobar que el procedimiento es correcto, incluimos la fragilidad (solo posible en simulación) en el modelo de PS y repetimos:

o <- oraculo |> mutate(trat = factor(isglt2, labels = c("No inicia", "Inicia iSGLT2")))
o$ps <- fitted(glm(as.formula(paste("isglt2 ~", x, "+ fragilidad")), data = o, family = binomial))
o$w <- ifelse(o$isglt2 == 1, 1 / o$ps, 1 / (1 - o$ps))

hr_f <- hr(coxph(Surv(tiempo_meses, evento) ~ isglt2, data = o, weights = w, robust = TRUE))
rf <- riesgo_ponderado(o, o$w, 36)
c(HR = unname(hr_f), DR_36m = unname(rf["DR"]), RR_36m = unname(rf["RR"])) |> round(3)
    HR DR_36m RR_36m 
 0.697 -0.050  0.719

HR 0.70, DR −5.0 puntos, RR 0.72: casi exactamente la verdad (0.70, −4.5, 0.74). El método funciona cuando el supuesto se cumple.

Cuando hay censura: IPCW

Aquí todos los pacientes tienen seguimiento completo hasta 36 meses o evento. Si hay censura informativa (pérdidas relacionadas con el pronóstico), el KM ponderado debe incluir también pesos por censura (IPCW): se estima la probabilidad de seguir en observación y se pondera a los no censurados por su inversa (Cap. 19).

Importante🎯 En resumen
  • Con desenlaces de supervivencia: KM ponderado (riesgos a t), Cox ponderado con errores robustos (HR marginal) o estandarización con un modelo de Cox.
  • Comunica el riesgo acumulado (DR, RR) a un tiempo fijo: más interpretable y colapsable que el HR.
  • El HR marginal ≠ HR condicional (no colapsabilidad).
  • Los IC deben provenir de bootstrap que repita todo el procedimiento.
  • El método es correcto, pero el resultado depende del supuesto de intercambiabilidad: con la fragilidad medida se recupera la verdad.
