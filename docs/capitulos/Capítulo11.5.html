Subgrupos y heterogeneidad

¿Para quién funciona?

Un efecto promedio puede esconder que el tratamiento funciona mejor en unos pacientes que en otros. En nuestro ECA se anticipa que el bicarbonato beneficia más a quienes tienen una acidosis más marcada. Es modificación del efecto (8.4) en un ensayo.

library(tidyverse)
library(broom)
library(emmeans)

eca <- read_csv("Bases/eca_bicarbonato.csv") |>
  mutate(brazo = factor(brazo, levels = c("Placebo", "Bicarbonato")),
         sexo = factor(sexo, levels = c("Mujer", "Hombre")),
         dif24 = tfg_24 - tfg0,
         edad_g = factor(edad >= 65, labels = c("<65 años", "≥65 años")),
         bic_g = factor(bic0 < 20, labels = c("Bicarbonato basal ≥20", "Bicarbonato basal <20")),
         dm_g = factor(dm, labels = c("Sin diabetes", "Con diabetes")),
         tfg_g = factor(tfg0 < 30, labels = c("TFGe basal ≥30", "TFGe basal <30")))

El análisis correcto: prueba de interacción

La pregunta no es “¿es significativo el efecto en cada subgrupo?” sino “¿difiere el efecto entre subgrupos?” Se contesta con el término de interacción brazo × subgrupo:

m_int <- lm(tfg_24 ~ brazo * bic_g + tfg0, data = eca)
m_sin <- lm(tfg_24 ~ brazo + bic_g + tfg0, data = eca)
anova(m_sin, m_int)                        # prueba de la interacción

Hay cierta evidencia de interacción (p ≈ 0.06): el efecto es mayor en quienes tienen bicarbonato basal < 20 mEq/L (1.9 vs. 0.8). Con un umbral dicotómico y un ensayo de este tamaño, el resultado queda en el límite; con el bicarbonato como variable continua (más abajo) la señal es algo más clara.

Forest plot de subgrupos

Se estima el efecto en cada subgrupo (con ANCOVA) y se prueba la interacción por separado. Una función reutilizable:

efecto_subgrupo <- function(datos, variable) {
  datos$sg <- datos[[variable]]
  m_i <- lm(tfg_24 ~ brazo * sg + tfg0, data = datos)
  m_s <- lm(tfg_24 ~ brazo + sg + tfg0, data = datos)
  p_int <- anova(m_s, m_i)$`Pr(>F)`[2]
  em <- emmeans(m_i, ~ brazo | sg) |> pairs(reverse = TRUE) |> summary(infer = TRUE)
  as_tibble(em) |>
    transmute(variable = variable, subgrupo = as.character(sg), diferencia = estimate,
              inf = lower.CL, sup = upper.CL, p_interaccion = p_int)
}

sub <- map_dfr(c("edad_g", "dm_g", "tfg_g", "bic_g"), \(v) efecto_subgrupo(eca, v))
global <- lm(tfg_24 ~ brazo + tfg0, data = eca) |> tidy(conf.int = TRUE) |>
  filter(term == "brazoBicarbonato") |>
  transmute(variable = "Global", subgrupo = "Todos", diferencia = estimate, inf = conf.low, sup = conf.high, p_interaccion = NA_real_)

forest <- bind_rows(global, sub) |>
  mutate(etiqueta = fct_rev(fct_inorder(paste(subgrupo))))
forest |> mutate(across(where(is.numeric), \(x) round(x, 2)))

Solo el subgrupo por bicarbonato basal muestra una señal de interacción (p ≈ 0.06); los demás tienen p de interacción de 0.2 o más y sus IC se solapan con el global: las diferencias entre ellos son compatibles con el azar.

Advertencia⚠️ El problema de la multiplicidad: “encontrar” subgrupos que no existen

Con cuatro subgrupos ya hay riesgo de hallazgos falsos; con 10-20, casi seguro. Lo comprobamos con una simulación sin ningún efecto (permutando el brazo al azar), midiendo la frecuencia con que al menos una de 10 interacciones sale con p < 0.05:

set.seed(2)
cuantos <- replicate(300, {
  d <- eca |> filter(!is.na(tfg_24)) |> mutate(brazo = sample(brazo))          # brazo permutado: sin efecto
  vars <- replicate(10, sample(c("a", "b"), nrow(d), TRUE))
  p <- apply(vars, 2, \(sg) {
    anova(lm(tfg_24 ~ brazo + sg + tfg0, d), lm(tfg_24 ~ brazo * sg + tfg0, d))$`Pr(>F)`[2]
  })
  any(p < 0.05)
})
mean(cuantos)       # proporción de ensayos "falsos" con al menos un subgrupo "significativo"
[1] 0.3733333

Con 10 subgrupos aleatorios, ~40 % de los ensayos sin efecto mostrarían al menos un “subgrupo significativo”. Por eso:

Tip💡 Reglas para creer un subgrupo (Sun et al., BMJ 2010)
  1. Preespecificado en el protocolo, con la dirección esperada.
  2. Pocos subgrupos (idealmente ≤ 3-5) con justificación biológica.
  3. Basado en una prueba de interacción, no en comparar valores p dentro de subgrupos.
  4. Consistente con otros ensayos o con datos biológicos.
  5. Una característica basal (no posterior a la aleatorización).
  6. Resultado replicado o confirmado en otro estudio.

Heterogeneidad continua: no dicotomices

Dicotomizar el bicarbonato (< 20 vs. ≥ 20) pierde información. El efecto se puede modelar como función continua:

m_cont <- lm(tfg_24 ~ brazo * I(bic0 - 20) + tfg0, data = eca)
tidy(m_cont, conf.int = TRUE) |> filter(str_detect(term, "brazo")) |> mutate(across(where(is.numeric), \(x) round(x, 3)))

El coeficiente de la interacción (≈ −0.37, p ≈ 0.03) indica que el beneficio aumenta ~0.4 mL/min/1.73 m² por cada mEq/L menos de bicarbonato basal (el valor verdadero ITT es ≈ −0.4; el IC es amplio). Un gráfico lo hace evidente:

oraculo <- read_csv("Bases/eca_bicarbonato_oraculo.csv")
verdad <- eca |> left_join(oraculo, by = "id") |>
  mutate(bic_bin = cut(bic0, c(0, 18, 19, 20, 21, 22, 30))) |>

  summarise(bic = mean(bic0), efecto_itt_real = mean(cumplidor * efecto_ind) * 2, .groups = "drop")

Efecto heterogéneo y decisiones

La heterogeneidad relativa (HR o RR) y la absoluta (diferencia de riesgos o de medias) pueden no coincidir (8.4). Para decidir a quién tratar, importa el beneficio absoluto esperado, que depende del efecto relativo y del riesgo basal del paciente. Los métodos que estiman el efecto individual esperado con muchas covariables (causal forests, meta-learners) se presentan en el Cap. 19; en un ECA pequeño son exploratorios.

Importante🎯 En resumen
  • Prueba la interacción; nunca compares valores p de subgrupos.
  • Preespecifica pocos subgrupos, basados en una característica basal con justificación biológica.
  • La multiplicidad produce falsos hallazgos: con 10 subgrupos, ~40 % de ensayos sin efecto muestran uno “significativo”.
  • Modela la variable modificadora como continua cuando sea posible; presenta un forest plot con el p de interacción.
  • Los subgrupos son generadores de hipótesis, salvo que estén preespecificados y confirmados.
