Intervalos de confianza y bootstrap

Del dato al intervalo

Una estimación sin su incertidumbre es incompleta. En el Cap. 6 vimos que el IC refleja el error de muestreo; aquí aprendemos a construirlo para los estadísticos más usados en nefrología. Simulamos un escenario realista: una pequeña cohorte de 120 pacientes extraída de nuestra población de 5 000 (así sabemos la verdad para comparar).

library(tidyverse)
library(boot)

ckd <- read_csv("Bases/ckd_isglt2.csv")
set.seed(1)
s <- slice_sample(ckd, n = 120)     # "nuestro estudio"
nrow(s)
[1] 120

¿Y si no existe una fórmula? El bootstrap

¿Cuál es el error estándar de la mediana de la UACR? ¿Y el de una razón de medianas o de un NNT? No hay fórmulas simples. El bootstrap las sustituye por un procedimiento:

  1. Toma, con reposición, una muestra del mismo tamaño que la tuya (una “muestra bootstrap”).
  2. Calcula el estadístico en esa muestra.
  3. Repite miles de veces.
  4. La variación de esos estadísticos aproxima la variación que tendrías en muestras nuevas.

Lo programamos “a mano” para entender la idea:

set.seed(10)
medianas <- replicate(2000, median(sample(s$uacr, replace = TRUE)))

c(mediana_observada = median(s$uacr),
  EE_bootstrap = sd(medianas),
  quantile(medianas, c(0.025, 0.975)))       # IC por percentiles
mediana_observada      EE_bootstrap              2.5%             97.5% 
        137.50000          16.26281          98.00000         159.50000 
tibble(mediana = medianas) |>
  ggplot(aes(mediana)) +

  geom_vline(xintercept = median(ckd$uacr), color = "#D55E00", linewidth = 1) +

El paquete boot

boot() hace lo mismo con más control y permite métodos de IC más finos (BCa, que corrige sesgo y asimetría). Se le entrega una función que recibe los datos y los índices de la muestra bootstrap:

mediana_fn <- function(datos, i) median(datos$uacr[i])

b <- boot(s, mediana_fn, R = 4000)

NotaPercentil vs. BCa
  • Percentil: simple y casi siempre razonable.
  • BCa: corrige sesgo y asimetría; es la opción más recomendada con muestras de tamaño pequeño o moderado, pero necesita más réplicas (≥ 2 000) y falla con muestras muy pequeñas.

Razón de medianas entre dos grupos

El bootstrap de dos muestras debe remuestrear dentro de cada grupo (strata), para mantener el tamaño de cada uno:

razon_med <- function(datos, i) {
  x <- datos[i, ]
  median(x$uacr[x$isglt2 == 1]) / median(x$uacr[x$isglt2 == 0])
}
set.seed(4)
s_300 <- slice_sample(ckd, n = 300)
b2 <- boot(s_300, razon_med, R = 4000, strata = s_300$isglt2)
c(estimado = b2$t0)

Diferencia de riesgos con IC bootstrap

El riesgo de evento renal a 36 meses es 19.2 % en los no tratados y 10.9 % en los tratados (crudo, sin ajustar). Su diferencia y su IC:

dr_fn <- function(datos, i) {
  x <- datos[i, ]
  mean(x$evento[x$isglt2 == 1]) - mean(x$evento[x$isglt2 == 0])
}
set.seed(5)
b3 <- boot(ckd, dr_fn, R = 2000, strata = ckd$isglt2)
ic3 <- boot.ci(b3, type = "perc")$percent[4:5]
c(dif_riesgos = b3$t0, IC_inf = ic3[1], IC_sup = ic3[2])
dif_riesgos      IC_inf      IC_sup 
-0.08313930 -0.10304896 -0.06290687 
## Comparación con la fórmula de Wald
p1 <- mean(ckd$evento[ckd$isglt2 == 1]); n1 <- sum(ckd$isglt2 == 1)
p0 <- mean(ckd$evento[ckd$isglt2 == 0]); n0 <- sum(ckd$isglt2 == 0)
(p1 - p0) + c(-1, 1) * 1.96 * sqrt(p1 * (1 - p1) / n1 + p0 * (1 - p0) / n0)
[1] -0.10272611 -0.06355249

Los dos IC casi coinciden: para estadísticos con fórmula, el bootstrap da lo mismo; su ventaja aparece cuando no hay fórmula (estimadores ajustados con IPW, g-fórmula, NNT). Esta diferencia es cruda: sin ajustar por las diferencias de la Tabla 1 no es el efecto causal.

Reglas del bootstrap

Advertencia⚠️ Cuándo el bootstrap falla o necesita cuidado
  • Datos agrupados (varios registros por paciente, pacientes dentro de centros): se remuestrean los pacientes (o centros) completos, no las filas.
  • Muestras muy pequeñas (n < 20) o estadísticos de extremos (máximo, percentil 99): el bootstrap no funciona bien.
  • No corrige sesgos de selección ni de medición; solo cuantifica el error de muestreo.
  • Fija la semilla (set.seed()) y usa suficientes réplicas (2 000-10 000).
  • Si el estimador incluye varios pasos (ajustar un modelo de propensión y luego ponderar), todo el proceso debe repetirse en cada muestra bootstrap.
Importante🎯 En resumen
  • Reporta siempre el IC junto a la estimación.
  • Para medias, proporciones y diferencias existen fórmulas (t.test, prop.test).
  • Para medianas, razones y estimadores complejos, el bootstrap: remuestrear con reposición, recalcular, repetir y mirar la variación.
  • Con boot(): función f(datos, i), R = 2000+, strata para dos grupos, boot.ci(type = c("perc","bca")).
  • Remuestrea unidades independientes (pacientes o centros), no filas dependientes.
