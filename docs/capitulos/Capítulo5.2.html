Manipular datos con dplyr

Las cinco funciones básicas de dplyr resuelven casi todo el trabajo diario. Todas se encadenan con el pipe |>.

Función Hace Ejemplo clínico
select() Elige columnas Quedarme con id, edad, creatinina
filter() Elige filas Solo pacientes con diabetes
mutate() Crea o modifica columnas Pasar creatinina a mg/dL
arrange() Ordena filas De mayor a menor UACR
summarise() + group_by() Resume por grupos TFGe media por categoría

Paso 2: normalizar el texto (stringr)

Tres funciones resuelven la mayoría de los casos:

Función Hace
str_trim() / str_squish() Quita espacios al inicio, al final y repetidos
str_to_lower() Convierte a minúsculas
str_detect() Detecta un patrón de texto (devuelve TRUE/FALSE) 
registro <- registro |>
  mutate(
    id_paciente = str_trim(id_paciente),                         # " P125" -> "P125"
    sexo_txt = str_to_lower(str_trim(sexo)),
    sexo = case_when(
      sexo_txt %in% c("f", "femenino")             ~ "F",
      sexo_txt %in% c("m", "masculino", "hombre")  ~ "M"        # lo que no encaja queda NA
    ),
    dm = if_else(str_to_lower(dm) %in% c("sí", "si"), "Sí", "No")
  ) |>
  select(-sexo_txt)

Advertencia⚠️ Cuidado con case_when(): lo que no coincide queda NA

Si agregas TRUE ~ "Otro" como última línea, todo lo no previsto pasa a “Otro” y pierdes la alerta de un valor inesperado. Para variables como sexo, es preferible dejar que lo inesperado aparezca como NA y revisarlo con count(..., sexo).

Paso 3: diagnóstico con varias escrituras

Cuando las variantes son muchas, normaliza primero (minúsculas, sin tildes ni espacios) y luego busca una palabra clave:

registro <- registro |>
  mutate(
    dx_norm = diagnostico |> str_squish() |> str_to_lower() |>
      stringi::stri_trans_general("Latin-ASCII"),               # quita tildes
    diagnostico = case_when(
      str_detect(dx_norm, "diabet")   ~ "ERC diabética",
      str_detect(dx_norm, "hipertens") ~ "ERC hipertensiva",
      str_detect(dx_norm, "glomerul")  ~ "Glomerulopatía",
      dx_norm == "otro"                ~ "Otro"
    )
  ) |>
  select(-dx_norm)

  mutate(

across(): la misma operación en varias columnas

registro |>
  summarise(across(c(edad, pas, pad), list(media = ~ mean(.x, na.rm = TRUE),
                                          maximo = ~ max(.x, na.rm = TRUE))))
# A tibble: 1 × 6
  edad_media edad_maximo pas_media pas_maximo pad_media pad_maximo
       <dbl>       <dbl>     <dbl>      <dbl>     <dbl>      <dbl>
1       57.9         176      171.       1400      80.9        109

El máximo de PAS (1400) delata un error de digitación. Resumir con frecuencia es la primera forma de detectar errores.

Tip💡 Tip práctico: receta de cuatro líneas para revisar una variable 
registro |> count(variable)                       # categorías
registro |> summarise(min(x), max(x), mean(x))    # rango
registro |> filter(is.na(x))                      # faltantes
registro |> filter(x < 0 | x > limite)            # imposibles
Importante🎯 En resumen
  • Cinco verbos: select, filter, mutate, arrange, summarise (+ group_by). Se encadenan con |>.
  • Antes de analizar, cuenta las categorías (count()): las variantes de escritura parten un grupo en varios.
  • Normaliza texto con str_trim, str_to_lower y quita tildes; luego unifica con case_when() + str_detect().
  • Deja que lo inesperado aparezca como NA en lugar de absorberlo en “Otro”.
  • Resumir (mínimos, máximos, tablas) es la mejor forma de encontrar errores.
