Introducción

La ciencia de datos en medicina es un campo amplio y en constante evolución. Este libro ofrece una base sólida de herramientas para el análisis de datos clínicos y la inferencia causal, pensado para residentes de nefrología: los ejemplos, los conjuntos de datos y el código parten de situaciones de la consulta (enfermedad renal crónica, diabetes, albuminuria, iSGLT2, diálisis).

Cómo usar este libro

Cada capítulo combina explicación, código reproducible y cuadros de apoyo:

Procesamiento de datos en medicina

El primer paso es importar los datos clínicos en R desde registros electrónicos o bases de datos. Luego se deben ordenar, asegurando que cada columna represente una variable y cada fila una observación.

Una vez estructurados, los datos pueden transformarse para enfocarse en poblaciones específicas (por ejemplo, pacientes con ERC G3b-G4), crear nuevas variables (como la categoría de TFGe) y calcular estadísticos descriptivos.

Visualización y modelado

La visualización es clave en medicina: permite detectar patrones en datos clínicos y epidemiológicos. Gráficos como las curvas de supervivencia o los diagramas de dispersión ayudan a interpretar tendencias y relaciones entre variables.

Los modelos permiten responder preguntas clínicas específicas. En inferencia causal se emplean regresión ajustada, emparejamiento, ponderación por puntaje de propensión y estandarización. Es crucial reconocer los supuestos de cada modelo, porque los modelos no pueden cuestionar sus propios supuestos.

Comunicación y programación

Transmitir resultados es esencial en investigación biomédica. No basta con obtener estimaciones precisas: hay que comunicarlas con claridad a clínicos y a quienes toman decisiones.

La programación automatiza tareas repetitivas y facilita análisis reproducibles. No se requiere ser un experto en R para seguir este libro; basta con conocer sus fundamentos.

Prerrequisitos

  1. Instalar R (≥ 4.2) y RStudio; para renderizar el libro, Quarto.
  2. Instalar los paquetes que usan los capítulos (se hace una sola vez):
install.packages(c(
  "tidyverse",        # manipulación y gráficos (dplyr, ggplot2, readr…)
  "broom",            # resultados de modelos en tablas ordenadas
  "survival",         # análisis de supervivencia
  "survminer",        # curvas de Kaplan-Meier
  "MatchIt",          # emparejamiento
  "marginaleffects",  # estandarización / efectos marginales
  "patchwork",        # combinar gráficos
  "DT",               # tablas interactivas
  "dagitty"           # diagramas causales (opcional para renderizar)
))
  1. Abrir el proyecto DataLab.Rproj y ejecutar los bloques de cada capítulo en orden. Las rutas son relativas a la carpeta capitulos/.
Advertencia⚠️ Cuidado: datos simulados

Todos los conjuntos de datos de este libro son simulados, para poder conocer el efecto verdadero y comprobar si cada método lo recupera. No usar estos resultados para decisiones clínicas.
