Instalar y orientarse en R y RStudio

R, RStudio y Quarto: ¿qué es cada cosa?

Programa Qué es Analogía
R El motor estadístico (el lenguaje) El motor de un auto
RStudio El entorno donde escribes y ejecutas código El tablero y el volante
Quarto El sistema que mezcla texto y código en un informe El procesador de textos que ejecuta tus análisis
Paquetes Extensiones con funciones adicionales (dplyr, survival…) Las aplicaciones que instalas
Tip💡 Tip práctico: orden de instalación
  1. Instala R (≥ 4.2) desde https://cran.r-project.org/.
  2. Instala RStudio Desktop desde https://posit.co/download/rstudio-desktop/.
  3. Instala Quarto desde https://quarto.org/docs/get-started/ (viene incluido en versiones recientes de RStudio).
  4. Abre RStudio y ejecuta, una sola vez, el bloque de instalación de paquetes de la Introducción.

Los cuatro paneles de RStudio

Panel Para qué sirve
Editor (arriba izquierda) Escribes scripts (.R) o documentos (.qmd). Es tu “cuaderno de laboratorio”
Consola (abajo izquierda) Donde R ejecuta las órdenes y muestra resultados
Entorno (arriba derecha) Los objetos que existen en este momento (bases, modelos)
Archivos / Gráficos / Ayuda (abajo derecha) Navegar carpetas, ver figuras y leer la ayuda de una función
Advertencia⚠️ Cuidado: escribe en el editor, no solo en la consola

Lo que escribes en la consola no queda guardado. Escribe tu código en un script o en un .qmd, ejecútalo con Ctrl/Cmd + Enter y guarda el archivo. Así tu análisis se puede repetir.

Proyectos: la mejor costumbre para evitar desastres

Un proyecto de RStudio es una carpeta con todo lo de un estudio (datos, scripts, informes). Al abrirlo, R trabaja desde esa carpeta, de modo que las rutas son relativas y el análisis funciona en cualquier computadora.

Estructura recomendada para un estudio:

mi_estudio/
├── mi_estudio.Rproj     <- abre este archivo para trabajar
├── datos/
│   ├── crudos/          <- datos originales (NUNCA se modifican)
│   └── procesados/      <- bases limpias generadas por el código
├── R/                   <- funciones propias
├── analisis/            <- scripts o .qmd numerados (01_limpieza.qmd, 02_tabla1.qmd…)
└── resultados/          <- tablas y figuras

Para crearlo: File → New Project → New Directory → New Project.

Importante🎯 Regla de oro de los datos

Los datos crudos no se tocan. Toda corrección (recodificar, excluir, corregir) se hace con código sobre una copia. Así siempre puedes explicar qué hiciste y repetirlo.

Rutas relativas y el paquete here

Una ruta absoluta (C:/Users/Daniel/Documentos/datos.csv) solo funciona en tu computadora. Una ruta relativa (datos/crudos/pacientes.csv) funciona en cualquier lugar si el proyecto se mantiene unido. El paquete here construye la ruta desde la raíz del proyecto:

library(here)

here()                                        # raíz del proyecto
here("datos", "crudos", "pacientes.csv")      # ruta al archivo, sin importar desde dónde ejecutes
Advertencia⚠️ Evita setwd()

setwd("C:/Users/...") rompe el análisis en cualquier otra computadora (incluida la tuya cuando cambies de carpeta). Usa un proyecto y here().

Importante🎯 En resumen
  • R hace los cálculos, RStudio es donde trabajas, Quarto crea informes, los paquetes amplían R.
  • Escribe siempre en scripts o .qmd, no solo en la consola.
  • Trabaja en un proyecto con rutas relativas (here).
  • Conserva los datos crudos intactos: todo cambio, con código.
