Epidat 4 es una aplicación multiplataforma. Su funcionamiento ha sido probado en numerosos sistemas operativos: Windows, MAC OS, Linux, Solaris… y en distintas versiones de estos sistemas.
 
Para funcionar correctamente, Epidat 4 requiere Java 6.0 Update 18 o superior.
Para descargar Java consulte http://www.java.com/es/download/.

Con la aplicación Java correctamente instalada sólo es necesario descomprimir el programa en una carpeta del disco duro que tenga permisos de escritura y ejecutar uno de los archivos: Epidat.jar o Epidat.bat.

Si no consigue ejecutar la aplicación consulte cómo se ejecutan los archivos “jar” en su sistema operativo. Si persiste el problema póngase en contacto con soporte.epidat@sergas.es.
  
Puede crear un acceso directo al programa en el escritorio; se adjuntan los iconos necesarios.

Para información sobre licencias consulte el archivo LICENCIAS.txt de la carpeta bin.
